# TyreBoss Website

Professional, mobile-first website for TyreBoss, a tyre repair and second-hand tyre business serving Mafeteng, Lesotho.

## Included
- Conversion-focused homepage
- Tyre repair and used-tyre service sections
- Email enquiry flow
- Responsive mobile navigation
- SEO metadata, robots.txt and sitemap.xml
- Privacy and terms pages
- No build step or framework dependency

## Deployment
This is a static site. Publish the repository root with GitHub Pages, Netlify, Vercel, or any standard static hosting provider.
